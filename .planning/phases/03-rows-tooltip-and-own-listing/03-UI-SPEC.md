# Phase 3 — UI Design Contract (Rows, Tooltip and Own Listing)

> Visual and interaction contract for the row details, the own-listing row, the hide button and the row tooltip. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This is a WoW Forever addon (interface 16001), not a web app. "Design system" = Blizzard's own UI: templates, atlases, font objects, colour globals and localized global strings. "Spacing" = anchor offsets, widths and heights in WoW UI pixels.
> Source tags: **[D-nn]** locked in 03-CONTEXT.md; **[G-nn]** research/UI-PARITY.md; **[P2]** Phase 2 UI-SPEC value carried over; **[auto]** decided here (author AFK, most stock-faithful choice); **[default]** gap filled with the nearest stock value.
> Blizzard paths relative to `wow-ui-source/Interface/AddOns/` (branch `forever`, read-only). `Browse.xml` = `Blizzard_GroupFinder_VanillaStyle/Mainline/Blizzard_LFGVanilla_Browse.xml`, `Browse.lua` = `Blizzard_GroupFinder_VanillaStyle/Blizzard_LFGVanilla_Browse.lua`.
> Everything not restated here is unchanged from `02-UI-SPEC.md` (frame extents 36 / 40, 620 width, column header, bottom bar, search states, section headers, row art).

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no shadcn, no npm) |
| Preset | not applicable |
| Component library | Blizzard templates. New this phase: `UIMenuButtonStretchTemplate` (delist and hide buttons; scripts are only on its own children, and we add ours, never `LFGBrowseDelistButtonMixin`). Everything else as Phase 2 |
| Icon library | Blizzard atlases (per element below); `W.Atlas` / `W.HasAtlas` probe each one and fall back |
| Font | Blizzard font objects only; no size or flag overrides in Lua |
| Hosts | In game: `LFGBrowseFrame` (`ns.Table.Attach`). Preview: the stand-in Browse panel with the same layers |
| Taint rule | Never inherit `LFGBrowseSearchEntryTemplate`, `LFGBrowseNestedSearchEntryTemplate` or `LFGBrowseDelistButtonMixin`; never write fields on Blizzard frames; never call `LFGBrowseSearchEntryTooltip_UpdateAndShow`, `LFGBrowse_DoSearch`, `LFGListingFrame:RemoveListing`, `LFGParentFrameTab1_OnClick` [UI-PARITY D9, D-12, D-15] |

Fallback rule (applies to every item below): where a template or atlas is missing (the preview stand-in on a client without it, or `C_XMLUtil.GetTemplateInfo` reports the template unknown) the element still renders and works with the fallback named in its row. Probe once through `TemplateKnown` / `W.HasAtlas`; never error.

## Spacing Scale

Pixel values copied from Blizzard source where stock has one; otherwise sized to fit the 40 px row [P2]. No 4 px grid applies.

### Row cell geometry (row height 40, cell height 32 centred) [P2]

| Column | Width | Change this phase |
|--------|-------|-------------------|
| Name | 150 | holds name text + optional Discord icon (below) |
| Lvl | 30 | none |
| Roles | 92 | solo micro icons (below) |
| Activity | flexible | absorbs the 4 px the action area grows by [D-21] |
| Listed | 44 | none |
| Action area (right) | `ACTIONS_W` = 24 + 3 + 66 + 2 = **95** (was 91) | hide button 24 wide [D-21] |

`GAP` between column groups stays 6. Header and rows keep sharing `Layout(header/row, ..., -(ACTIONS_W + GAP))`, so the column header strip stays aligned. Constants to change in `UI/Table.lua`: `HIDE_W` 20 -> 24; `ACTIONS_W` formula unchanged (`HIDE_W + 3 + MSG_W + 2`) [D-21].

### Solo micro role icons (Roles cell, 92 wide) [D-05, auto]

| Property | Value |
|----------|-------|
| Atlas | `groupfinder-icon-role-micro-tank` / `-heal` / `-dps` (stock `SOLO_TANK/HEALER/DAMAGER`) |
| Size | **18 x 18** each, set explicitly (`SetAtlas(name, false)` then `SetSize(18, 18)`; stock is 23 at row 72; 18 fits the 32 px cell with room beside the comment line) |
| Spacing | 2 px between icons (step 20) |
| Order and packing | T > H > D, only the roles the player can play, packed from the LEFT of the cell (stock `MapRoleStatesToRoleIcons`, `useSimple`) |
| Vertical | centred in the cell |
| Max width | 3 x 18 + 2 x 2 = 58 of 92, always fits; never wraps |
| Greyed row | `SetDesaturated(true)`, alpha 0.5 [P2] |
| Group rows | unchanged: `groupfinder-icon-role-large-*` at the current slot size (14), open slots from `l.remaining`, else `COMPOSITION` [D-06]; the "T1 H1 D3" text for size > 5 stays (G18 deferred) |
| Fallback (micro atlas missing) | the existing large-icon slot (14 px) or letter square, same packing order, same left origin |

Every `FillRow` sets all three icon states (shown/hidden, atlas, size, desaturation) because ScrollBox frames are reused; a solo row followed by a group row on the same frame must reset the size to the large-slot size.

### Discord icon (Name cell) [D-07, auto]

| Property | Value |
|----------|-------|
| Atlas | `UI-ChatIcon-Discord` |
| Size | **16 x 16** |
| Placement | LEFT of the icon = RIGHT of the name text + **4** px, vertically on the name line (same Y centre as the name text, not the cell centre) |
| Name width bound | name FontString width is clamped to `150 - 16 - 4 = 130` when the icon shows, so a long name truncates (ellipsis) before the icon; with no icon the name gets the full 150 |
| Shown when | `l.voiceMode == Enum.LFGEntryVoiceMode.Discord` only; Legacy / Custom / None / secret / nil: hidden |
| Greyed row | `SetDesaturated(true)`, alpha 0.5 |
| Fallback (atlas missing) | the existing `W.Icon("voice")` text tag, same anchor, same visibility rule; a missing `Enum.LFGEntryVoiceMode` hides it (preview samples carry `voiceMode` per [D-04]) |

### Delist button (own row only) [D-10, D-11, G22]

| Property | Value |
|----------|-------|
| Frame | our own `Button` inheriting `UIMenuButtonStretchTemplate` (no mixin, no `LFGBrowseDelistButtonMixin`) |
| Size | **24 x 22** |
| Anchor | RIGHT of the row, x **-8**, y 0 (stock `Browse.xml:114-135`) |
| Icon | `groupfinder-icon-redx`, texture on ARTWORK, `useAtlasSize` (`SetAtlas(name, true)`), CENTER 0,0 |
| Highlight | `Interface\Buttons\UI-Common-MouseHilight`, ADD blend |
| Visible | own row AND (solo OR `ns.IsLeader()`); otherwise `Hide()` (never disabled) |
| Fallback (template unknown) | `W.Button` 24 x 22 with the redx atlas centred at atlas size, or the text "x" if the atlas is missing |
| Frame level | above the row's click area; clicking never selects the row (own row is not selectable [P2]) |

### Hide / show button (all other rows) [D-20, D-21, G23]

| Property | Value |
|----------|-------|
| Frame | our own `Button` inheriting `UIMenuButtonStretchTemplate` |
| Size | **24 x 22** |
| Anchor | RIGHT of the row, x **-2**, y 0 (replaces `RIGHT -2` of the 20 px button); Whisper (66 x 20) stays anchored RIGHT of hide with x **-3** |
| Icon | **16 x 16** centred (explicit size, not atlas size: the eye atlases are larger than the button's inner area) |
| Icon: hide | `transmog-icon-hidden` (eye struck through), shown on a normal row |
| Icon: show | `socialqueuing-icon-eye` (open eye), shown on a hidden row |
| Not used | `groupfinder-icon-redx` (means unlist in stock) and `common-icon-redx` (reads as delete) |
| Highlight | `UI-Common-MouseHilight`, ADD |
| Greyed row | the button stays fully visible and enabled so the row can be un-hidden; only its icon swaps |
| Fallback (template or atlas missing) | `W.Button` 24 x 22 with text "x" (hide) / "+" (show), as today |
| In-game check | atlas choice is confirmed in game (UI-PARITY Q10); if `transmog-icon-hidden` reads poorly, use the text "x" / "+" fallback (never `common-icon-redx`) |

Both buttons come from one builder in `UI/Widgets.lua` (e.g. `W.IconButton(parent, w, h)`) returning the button and its `.icon`, so size, highlight and fallback live in one place [Claude's Discretion].

### Own row (look) [D-09, D-10, D-13]

Row art stays `groupfinder-highlightbar` (+ blue hover) [P2]. Layout identical to any row, except: no Whisper, no hide button, the delist button in their place (Activity cell width already reserves `ACTIONS_W`, so nothing shifts).

### Tooltip geometry [D-15, auto]

`GameTooltip`, `SetOwner(row, "ANCHOR_RIGHT")`, default `GameTooltip` backdrop and padding. Inline atlas markup sizes: leader icon 16, role icons 14 (leader line and member lines), new-player icon 14. Wrap width: comment and friends lines `wrap = true`; activity names do not wrap.

|-------------|-----------|-------|

### Tooltip refresh [D-19, G37]

- Trigger: at the end of every `Instance:Refresh` (after the list is re-filled), and in the `W.List` fallback path too.
- Condition: `GameTooltip:IsShown()` and `GameTooltip:GetOwner()` is one of this table's row frames.
- If that row frame is still `IsMouseOver()` and holds a listing: re-run `ShowTooltip(row)` with the row's current listing (the frame may now hold a different listing; the tooltip follows what is under the mouse).
- Else: `GameTooltip:Hide()`.
- No timers and no OnUpdate; the refresh rides on the existing event-driven `Refresh`. A scroll-induced re-bind is handled by the same rule on the next `Refresh`, and the row's `OnEnter` already covers mouse movement.

## Tooltip Contract (line by line) [D-16, D-17, G26]

Order is fixed. Blank = `AddLine(" ")`, one line each; a block that is not shown contributes no blank line (never two blanks in a row, never a leading or trailing blank). Inline icons use `CreateAtlasMarkup(atlas, h, h)` (falls back to the `|A:atlas:h:h|a` form; where `CreateAtlasMarkup` is nil use the form directly; where the atlas is missing, omit the icon, never show raw markup). Strings are Blizzard globals with the English fallback after `or`.

| # | Block | Shown when | Text (global or fallback) | Colour | Notes |
|---|-------|-----------|---------------------------|--------|-------|
| 1 | Delisted | `l.delisted` | `LFG_LIST_ENTRY_DELISTED` or "Delisted" | red | first line when present |
| 2 | New player friendly | `l.newPlayerFriendly` and not delisted | atlas `newplayerchat-chaticon-newcomer` (14) + space + `LFG_LIST_NEW_PLAYER_FRIENDLY_HEADER` or "New player friendly" | green | |
| 3 | Leader line | always (if leader known) | `[leader icon 16 + ]` name + friend marks, then 2 spaces, `LEVEL_ABBR .. " " .. level` (or "Lvl N"), then 2 spaces, role icons | name: class colour; level: `GRAY_FONT_COLOR`; icons: none | leader icon `groupfinder-icon-leader` only for groups (members > 1). Solo roles: micro icons (14) for every role they can play, T > H > D. Group: the leader's assigned role, large icon (14). One line (single `AddLine`). Level colour inline via `|cff...|r` |
| 4 | Members | group, 2 to 10 members, non-leaders | 3 spaces indent (aligned under the leader name), class-coloured name + marks, 2 spaces, `LEVEL_ABBR level` grey, 2 spaces, assigned role large icon (14) | as row 3 | one line per member in listing order; more than 10 members: this block is skipped entirely (no "... and N more" line) |
| — | blank | blocks 3/4 shown and anything follows | | | |
| 5 | Comment | `l.comment` non-empty | `string.format(LFG_LIST_COMMENT_FORMAT or '"%s"', comment)` | `LIGHTGRAY_FONT_COLOR`, wrap | followed by a blank |

| 7 | Voice chat | a label exists for `l.voiceMode` | `format(VOICE_CHAT_MODE_FORMAT, label)`, label = `VOICE_CHAT_MODE_NONE / LEGACY / DISCORD / CUSTOM` per mode | `NORMAL_FONT_COLOR` | directly under 6, no blank. Globals or enum missing: "Voice chat: " .. English mode name; `voiceMode` nil: no line |
| — | blank | | | | |
| 8 | Activities | at least one activity | groupless activities first, one per line, no indent; then each activity group: group name line, its activities below indented by `LFG_LIST_INDENT` (fallback 3 spaces) | bright blue if the activity is in your active listing's activities (`C_LFGList.GetActiveEntryInfo().activityIDs`; preview: `ns.state.myListing`), else gray; a group name is bright blue if any child matches | group info from `C_LFGList.GetActivityGroupInfo(groupID)`; no group info (preview): flat list of activity names, same colours. A 6 px gap between groups is a blank line only when there is more than one group; otherwise none |
| — | blank | block 9 shown | | | |
| 9 | Bosses defeated | exactly one activity and `GetSearchResultEncounterInfo` returns names (read on show only) | header `LFG_LIST_BOSSES_DEFEATED` or "Bosses defeated:" (`NORMAL_FONT_COLOR`), then one line per boss, 3 spaces indent, red | red | pcall + secret guard; empty: skip header too |
| — | blank | any extra follows | | | |
| X1 | Playstyle | `l.playstyle` known | `GetGeneralPlaystyleString(l.playstyle)`; fallback the preview's playstyle text | `GREEN_FONT_COLOR` | first extra [D-17] |
| X2 | Spec / area | solo with spec or area | "spec, area" (existing text) | gray | |

| X4 | Listed | always | "Listed " .. age .. " ago" | gray | no voice flag here any more |
| X5 | Hidden note | `IsHidden(l)` | "Hidden until they make a new listing (+ to show)." | gray, wrap | always last |

Dropped from the old tooltip: the gold activity title line, "Can play:", "Looking for:", "Members: n/m" line, the "voice chat" tag in the Listed line. GS lines remain only behind `ns.GEAR_SCORE` (off) and, when on, go on the leader and member lines as a right-hand `AddDoubleLine` column [D-17].

Blank-line rule in practice: after block 4 (or 3) if any of 5-9/extras follow; after 5; before 8 (after 7); before 9; before the extras. Collapse duplicates.

The tooltip is built from two helpers: `StockTooltip(l)` (blocks 1-9) and `ExtrasTooltip(l)` (X1-X5); `GameTooltip:Show()` is called once at the end so the tooltip sizes to its content.
