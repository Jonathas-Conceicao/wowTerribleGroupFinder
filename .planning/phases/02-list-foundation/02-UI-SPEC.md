# Phase 2 — UI Design Contract (List Foundation)

> Visual and interaction contract for the Browse list rebuild. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This is a WoW Forever addon (interface 16001), not a web app. "Design system" = Blizzard's own UI: XML templates, atlases, font objects, colour globals and localized global strings. "Spacing" = anchor offsets, heights and widths in WoW UI pixels, copied from Blizzard source.
> Source tags: **[D-nn]** locked in 02-CONTEXT.md; **[G-nn]** recommendation in research/UI-PARITY.md (auto-accepted); **[default]** gap filled with the most stock-faithful choice.
> Blizzard paths are relative to `wow-ui-source/Interface/AddOns/` (branch `forever`, read-only). `Browse.xml` = `Blizzard_GroupFinder_VanillaStyle/Mainline/Blizzard_LFGVanilla_Browse.xml`, `Browse.lua` = `Blizzard_GroupFinder_VanillaStyle/Blizzard_LFGVanilla_Browse.lua`.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no shadcn, no npm; Blizzard templates and atlases via `W.Create` / `W.Atlas` with fallbacks) |
| Preset | not applicable |
| Component library | Blizzard UI templates: `WowScrollBoxList`, `MinimalScrollBar`, `LFGBrowseSearchEntryGroupingTemplate` (in game only, scriptless), `ColumnDisplayButtonShortTemplate`, `SearchBoxTemplate`, `UICheckButtonTemplate`, `LoadingSpinnerTemplate`, `UIPanelButtonTemplate`. Our own `UI/Templates.xml` (plain virtual Buttons, no inheritance, no scripts) |
| Icon library | Blizzard atlases (listed per element below); `W.Atlas` falls back to a plain colour texture where an atlas is missing |
| Font | Blizzard font objects (listed per element); no custom fonts |
| Hosts | In game: `LFGBrowseFrame` (via `ns.Table.Attach`). Preview: the stand-in `LFGParentFrame` Browse panel, which mirrors the same layers |
| Taint rule | Never inherit `LFGBrowseSearchEntryTemplate` / `LFGBrowseNestedSearchEntryTemplate`; never write fields on Blizzard frames; read `LFGBrowseFrame.searching` / `.searchFailed` only [D-04, D-25, D-26] |

## Spacing Scale

WoW pixels are not on a 4 px grid: anchor offsets are copied from Blizzard source so our frames sit on the finder's own geometry. The web 4-point scale does not apply; the contract is the fixed values below. Any value not listed here follows the nearest stock anchor and is marked [default].

## Typography

Declared as Blizzard font objects (sizes are what the objects resolve to in the Forever client; never override size or flags in Lua).

| Role | Font object | Where used |
|------|-------------|------------|
| Row name | `GameFontNormal`, class colour (`RAID_CLASS_COLORS`) | Name cell (table density; stock is `GameFontNormalLarge`) [D-21, G14] |
| Section header label | `GameFontNormal` (gold) | Header label [D-07] |
| Level | `GameFontDisable` (grey) | Lvl cell, number only [D-21, G16] |
| Activity | `GameFontHighlightSmall` with colour override | Activity cell [D-21] |
| Comment line | current font unchanged (`GameFontDisableSmall`) | second line; light grey is Phase 3 [D-21] |
| Column header | `GameFontHighlightSmall` (template default) | `ColumnDisplayButtonShortTemplate` [D-15] |
| Bottom status | `GameFontHighlightSmall` | "N solo players, M groups" [D-17] |
| Checkbox label | `GameFontNormalSmall` (template `.Text`, gold) | Needs my role, Messages tab checkboxes [D-29] |
| Searching label | `GameFontNormalLarge` | spinner caption [D-25] |
| Empty / failed / filtered text | `GameFontDisable` | state text [D-26, D-27] |

Weights: Blizzard fonts carry their own weight (no weight choice). Line height: font-object default; row text is two lines in 40 px (name line + comment line), no custom line spacing.

## Color

Colours are Blizzard colour globals and atlases; raw RGB only for the one value stock itself hard-codes.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (about 60%) | `groupfinder-background` art inside Forever's own `Inset` | list surface; no second inset [D-13] |
| Secondary (about 30%) | `common-button-list-mid2` row bars, `common-button-list-collapseExpand` header bars, `groupfinder-Stat-StoneBG` band | rows, headers, header band |
| Accent (about 10%) | `BRIGHTBLUE_FONT_COLOR` | Activity text only when one of its activities matches your active listing's activities [D-21] |
| Muted | `GRAY_FONT_COLOR` | Activity text by default; header count; level |
| Greyed (demoted) | `{0.3, 0.3, 0.3}` | all row text of hidden / delisted / no-slot rows (stock delisted grey), class-coloured names too [D-22] |
| Destructive | none in this phase | |

Accent reserved for: Activity text matching the player's active listing (`BRIGHTBLUE_FONT_COLOR`); selected-row art (`common-button-list-mid2-selected`); hover art. Nothing else.

Icon treatment: greyed rows set class / leader / role icons `SetDesaturated(true)`, role icons at alpha 0.5, restored on reuse [D-22]. Group rows show `groupfinder-icon-leader` instead of the class icon (fallback: class icon); solo rows keep the class icon [D-23]. Role icons stay the current large atlases this phase (micro icons are Phase 3).

## Interaction Contract

| Interaction | Behaviour | Sound |
|-------------|-----------|-------|
| Click section header | toggles `view.collapsed[key]`, swaps plus/minus icon; hover only brightens its own atlas | none [D-07, D-08] |
| Click column header | sorts as today (same column flips, FIRST_DESC); arrow `auctionhouse-ui-sortarrow` ascending texcoord 0,1,1,0, descending 0,1,0,1; fallback flat button with "^" / "v" | none [D-15] |
| Click result row | toggles selection by `inst.selectedID` (result ID). Delisted rows and own listing: nothing happens | `SOUNDKIT.IG_MAINMENU_OPTION_CHECKBOX_ON` for select and deselect; none for ignored clicks [D-09, D-11] |
| Double-click row | removed (no whisper) | [D-11] |
| Right-click row | nothing this phase | [D-11] |
| Hide (X) / show (+) | hides / unhides listing | `IG_MAINMENU_OPTION_CHECKBOX_ON` [D-28] |
| Checkbox (Needs my role, Messages checks) | toggles | ON when checked, OFF when unchecked [D-28] |
| Send Message | enabled for any selection | stock [D-12] |
| Group Invite | enabled for a selected solo listing when `ns.CanInvite()` | stock [D-12] |
| Selection cleared | on `LFG_LIST_SEARCH_RESULTS_RECEIVED`, `LFG_LIST_SEARCH_FAILED`, search start (`LFGBrowse_DoSearch` hook), selected ID gone or delisted after a read, preview refresh button | [D-10] |
| Selection kept | across re-sort, hide, and a re-read where the ID is present and not delisted | [D-09] |
| Scrolling | mouse wheel and draggable `MinimalScrollBar`; bar hidden when the list fits; refresh and re-sort keep scroll position (`ScrollBoxConstants.RetainScrollPosition`) | none [D-02] |
| Hovering a row | stock hover art; tooltip as today (order changes are Phase 3) | none |

### Screen states

| State | Visible |
|-------|---------|
| Searching (`LFGBrowseFrame.searching`) | list emptied; spinner + `SEARCHING` label [D-25] |
| Search failed (`LFGBrowseFrame.searchFailed`) | `LFG_LIST_SEARCH_FAILED` text [D-26] |
| No results | `LFG_LIST_NO_RESULTS_FOUND` text [D-26] |
| Results, all filtered by our search box | "No listings match your search." even if your own row remains [D-27] |
| Preview, nothing in chosen activities | `LFG_LIST_NO_RESULTS_FOUND` [D-27] |
| Results present | own listing, Solo players section, Groups section (order per CLAUDE.md), each with its 36 px header |
| ScrollBox API missing | `W.List` fallback with one pool per item kind (header 36 / row 40) and the 4 px gold thumb [D-05] |

## Copywriting Contract

Stock strings come from Blizzard global strings so they localize; only the strings marked "ours" are ours.

| Element | Copy |
|---------|------|
| Primary CTA (bottom bar) | `SEND_MESSAGE` (stock label) and `GROUP_INVITE` (stock label), unchanged |
| Row button | "Whisper" (ours, unchanged) |
| Section labels | `LFG_LIST_CATEGORY_SOLO_PLAYERS`, `LFG_LIST_CATEGORY_GROUPS`, followed by our count in `GRAY_FONT_COLOR` |
| Searching | `SEARCHING` |
| Empty state (no results) | `LFG_LIST_NO_RESULTS_FOUND` |
| Error state (search failed) | `LFG_LIST_SEARCH_FAILED` (stock text; the refresh button is the retry path) |
| Filtered by our search box | "No listings match your search." (ours; next step is implied: clear the search box) |
| Search box instructions | "Name, activity or note" (ours) |
| Bottom status | "N solo players, M groups" (ours, existing format) |
| Needs my role | "Needs my role" (ours, existing) |
| Own listing suffix | "(you)" stays this phase; "Your listing" in green is Phase 3 [D-24] |
| Destructive actions | none added. Hide (X) is reversible (+ shows it again), so no confirmation |

The old "Nothing listed here..." line is removed [D-27].
