# Phase 04.1 — UI Design Contract (Player location)

> Visual and interaction contract for the zone shown on each Browse row (line 2 of the Activity cell) and the zone on the member lines of a group's tooltip. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This is a WoW Forever addon (interface 16001), not a web app. "Design system" = Blizzard's own UI: font objects, colour globals, atlases. "Spacing" = anchor offsets and widths in WoW UI pixels. No 4 px grid applies.

## Row: zone on line 2 of the Activity cell [D-01 to D-06]

No new column. The fixed left columns, Listed, the buttons and Activity's flexible span are untouched [D-03]. Row height is unchanged (line 2 already exists).

### Elements (all children of `cells.activity`, built once in `BuildRow`)

| Element | Font | Anchor | Width bound |
|---------|------|--------|-------------|
| `row.activity` (line 1) | `GameFontHighlightSmall` 11 | unchanged: TOPLEFT (0, -4), RIGHT (0, 0) | unchanged |
| `row.zone` (new, line 2 left) | `GameFontDisableSmall` 10, left justified, one line, no wrap | TOPLEFT (0, -19) | `SetWidth(ZoneWidth)` per fill, see below |
| `row.comment` (line 2) | `GameFontDisableSmall` 10, unchanged | TOPLEFT = `row.zone` TOPRIGHT, x **ZONE_GAP**; RIGHT (0, 0) of the cell, when a zone is shown. Otherwise TOPLEFT (0, -19) as today | cell right edge (unchanged) |

Both strings: `SetWordWrap(false)`, `SetMaxLines(1)`, so a long zone is cut, never wrapped [D-02].

### Numbers [auto]

| Constant | Value | Reasoning |
|----------|-------|-----------|
| `ZONE_MAX` | **100 px** | hard cap, below the 110 px ceiling in D-02. About 18 characters at 10 pt (about 5.5 px/char): "Stranglethorn Vale" (18) just fits, "The Temple of Atal'Hakkar" (25) is cut |
| `ZONE_FRAC` | **0.45** of the Activity cell's width | D-02 |
| `ZoneWidth` | `max(1, min(ZONE_MAX, floor(cellWidth * ZONE_FRAC), zone:GetStringWidth()))` | the string never takes more than its text needs, so a short zone ("Orgrimmar") leaves the comment close to it. At the 620 px layout (Activity about 130 px) the cap is 58 px; at wider layouts it grows to 100 |
| `ZONE_GAP` | **6 px** | one visible gap between zone and comment; the comment keeps the rest of the cell |

Measuring: set the zone text first, read `GetStringWidth()` (untruncated while the FontString has no width yet), then `SetWidth`. If the cell width is not yet known (0) at fill time, use `ZONE_MAX`; the FontString is still clipped by its own width.

With both a zone and a comment, the comment starts at x = ZoneWidth + 6 and may be cut short at 620 px with a long zone: accepted. The full zone is in the tooltip and the full comment is in the tooltip too [D-10]. No minimum comment width is enforced.

### States

| State | Zone | Comment |
|-------|------|---------|
| Zone and comment | shown, colour per below | shown after the gap |
| Zone only | shown alone | empty text |
| Comment only (no zone) | `row.zone:SetText("")`, `Hide()` | anchored at TOPLEFT (0, -19) as today [D-02] |
| Neither | both empty | both empty, as today |
| Your own row (`l.mine`) | not shown [D-05] | as today |
| Zone missing, nil, empty or secret | not shown; nothing else changes [D-06, D-07] | as today |
| Solo listing | `l.leader.area` (the player's) | |
| Group listing | `l.leader.area` (the leader's) | |

Re-anchor on every fill (frames are pooled): `ClearAllPoints` on `row.comment`, then set the anchor for the current state. `row.zone` is set, sized and shown or hidden on every fill.

### Colour [D-04]

| Row kind | Zone colour |
|----------|-------------|
| Normal row | `W.GRAY` (stock `GRAY_FONT_COLOR`), set on every fill |
| Greyed row (hidden, delisted, no slot for you) | `W.DELISTED`, like every other text on a greyed row: add `row.zone` to the `texts` list in `FillRow` |
| Selected / hover | no change |

The comment keeps `W.LIGHTGRAY`, so zone (darker grey) and comment (lighter grey) stay distinguishable without a separator character.

## Tooltip [D-08 to D-10]

### Solo

Unchanged [D-08]: the existing grey "spec, zone" line from `ExtrasTooltip` already shows the full zone.

### Group: zone on the member lines (refines D-09)

No separate block, no label, no new header. In `StockTooltip` the leader line and (groups of 10 or fewer) one line per member already go through `tip.line(left, WHITE, false, right)`; the 4th argument is the right-hand text of a double line. The zone becomes that right-hand text.

| Aspect | Contract |
|--------|----------|
| Lines | the leader line and each member line already written; nothing is added: no blank line, no label |
| Right text | the zone in `W.GRAY` (colour code + zone + `|r`), right-aligned by the double line |
| Gear Score on (`ns.GEAR_SCORE`) | zone first, then GS, right side as today: `<gray zone>  GS x` (two spaces between). The leader keeps its "GS " prefix, members as today |
| Gear Score off (this release) | the right text is the zone alone |
| Member without a zone | no right text; the line is unchanged. No placeholder, no dash |
| Zone text | full name, never truncated by us |
| Groups of more than 10 members | the stock tooltip lists no members, so no per-member zones are shown; this follows Forever's tooltip. The row still shows the leader's zone |
| Name, class colour, indent | unchanged (existing `PlayerText`, 3-space member indent) |
| Own listing | no zone [D-05] |
| Greyed listing | same tooltip as any other |

Example (GS off, leader and 3 members, 3 with a zone):

```
Leader line       Stranglethorn Vale
   Kaelis         Stranglethorn Vale
   Murgul         Orgrimmar
   Tessa
```

## In-game Checks

- Zone at 620 px, Gear Score on and off: line 2 reads cleanly; a cut zone shows an ellipsis; comment not squeezed to nothing for ordinary zone names.
- Pooled rows: scroll quickly; a row reused for a listing without a zone shows no stale zone and the comment is back at x 0.
- Greyed rows (X, delisted, no slot for you): zone in the delisted grey.
- Group tooltip: zones right-aligned on the leader and member lines; a group with no known zones looks exactly as before; a group over 10 members shows no per-member zones.
- Secret `areaName`: row and tooltip show nothing for that zone; no Lua error.
