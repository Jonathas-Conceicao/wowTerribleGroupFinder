## Critical Issues

### CR-01: Own group listing shows member zones in the tooltip while Gear Score is off

**File:** `UI/Table.lua:531-537`
**Issue:** The member line passes `l.mine and memberGS or RightText(m, memberGS)`. With `ns.GEAR_SCORE` false (`Core.lua:15`), `memberGS` is always nil, so for your own listing the `and/or` falls through to `RightText(m, nil)` and shows zones on your own group's member lines, against D-05. Real in game: `l.mine = info.hasSelf` and its members come from `GetSearchResultPlayerInfo`, which fills `area`. The leader line is safe (its fallback is `leaderGS`).
**Fix:** compute `right = memberGS`, and only when `not l.mine` set `right = RightText(m, memberGS)`.

## Warnings

### WR-01: A zone that exactly fits can still be cut with an ellipsis

**File:** `UI/Table.lua:828-833`
**Issue:** `FitZone` sets the width to exactly `GetStringWidth()`; sub-pixel float differences can make the FontString truncate a string that fills its width exactly ("Orgrimm...").
**Fix:** `math.min(cap, math.ceil(textWidth) + 1)`.

### WR-02: A malformed preview member spec raises a Lua error

**File:** `Preview.lua:79-82`
**Issue:** When the pattern does not match, `rest` is nil and `rest:match(...)` throws, stopping the whole preview load (before, a bad spec just gave a nil name).
**Fix:** `local zone = rest and rest:match("^@(.+)$")`.

### WR-03: The zone fit depends on OnSizeChanged alone after a width change

**File:** `UI/Table.lua:889-898`
**Issue:** If the cell is 0 wide at fill, the cap falls back to `ZONE_MAX` and is corrected only by `OnSizeChanged`. A width change that doesn't fire a size change on the cell would leave a stale cap. The spec says the cap is recomputed "on the next fill/Layout".
**Fix:** also refit the zone where the layout is (re)applied, not only from the hook.

## Info

**File:** `UI/Table.lua:899-901`

### IN-02: Zone text is concatenated into a colour-code string unescaped

**File:** `UI/Table.lua:482`
**Fix:** escape `|` (`gsub("|", "||")`) before wrapping in the grey colour code.
