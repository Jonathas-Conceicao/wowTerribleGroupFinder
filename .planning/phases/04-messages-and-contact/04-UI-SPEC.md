# Phase 4 — UI Design Contract (Messages and Contact)

> Visual and interaction contract for the Messages side tab, the Messages panel, the key buttons, Auto-send / Auto-invite and the "sending" look of the contact buttons. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This is a WoW Forever addon (interface 16001), not a web app. "Design system" = Blizzard's own UI: templates, atlases, font objects, colour globals. "Spacing" = anchor offsets, widths and heights in WoW UI pixels. No 4 px grid applies.
> Source tags: **[D-nn]** locked in 04-CONTEXT.md; **[G-nn]** research/UI-PARITY.md; **[P2]/[P3]** value carried over from the Phase 2 / 3 UI-SPEC; **[auto]** decided here (author AFK, most stock-faithful choice); **[default]** gap filled with the nearest stock value.
> Blizzard paths relative to `wow-ui-source/Interface/AddOns/` (branch `forever`, read-only). `Who.xml` = `Blizzard_GroupFinder_VanillaStyle/Mainline/WhoList.xml`, `Parent.xml` = `Blizzard_GroupFinder_VanillaStyle/Mainline/Blizzard_LFGVanilla_ParentFrame.xml`.
> Everything not restated here is unchanged from `02-UI-SPEC.md` and `03-UI-SPEC.md` (table, rows, tooltip, bottom bar).

## Key buttons [D-06, D-07, G32]

| Property | Value |
|----------|-------|
| Template | `UIPanelButtonTemplate` via `W.Button` variant, **22 tall**, width = `GetStringWidth()` of the label + **24** (stock `Listing` pattern, G32) |
| Font | `GameFontNormalSmall` (`SetNormalFontObject` / disabled `GameFontDisableSmall`); label is the key text itself, e.g. `{activity}`; the addon key's label is `[TGF]` |
| Gap | 4 px between buttons in a row (`LEFT` of next = `RIGHT` of previous, x 4) |
| Rows | **Two rows, explicit break** (all 7 do not fit one row: widths below). Row 1 (x origin 0): `[TGF]`, `{name}`, `{activity}`, `{players}`. Row 2 (x origin 0, y pitch 24): `{class}`, `{level}`, `{role}` |
| Grouping rationale | row 1 = the message tag, the contact and the group (about them / the party); row 2 = about you. `[TGF]` first as required [D-06] |
| Estimated widths | at ~5.8 px/char: row 1 = (5+6+10+9) x 5.8 + 4 x 24 + 3 x 4 = **282**; row 2 = (7+7+6) x 5.8 + 3 x 24 + 2 x 4 = **196**. Both under 422 (and under the 410 box width). One row of 7 = 50 chars x 5.8 + 7 x 24 + 6 x 4 = **482 > 422**, hence two rows |
| Guard | widths are measured at build; if a row would exceed 410 (long fonts, other locale) the builder wraps greedily to a further row only as a guard; layout above is the contract |
| Disabled | never disabled |
| Click | `[TGF]`: puts `{addon} ` at the front, no-op if already first, cursor after it. Others: `EditBox:Insert(key)` at the cursor, then `SetFocus()`, then save/normalise [D-07]. Sound: `SOUNDKIT.IG_MAINMENU_OPTION_CHECKBOX_ON` via `W.PlayCheckbox` is **not** played (plain button click sound from the template) [auto] |
| Tooltip | `GameTooltip`, `ANCHOR_RIGHT`, title (NORMAL gold) + one `HIGHLIGHT_FONT_COLOR` wrapped line; see Copywriting |

## Checkboxes, Default, Example

| Element | Contract |
|---------|----------|
| Auto-send | `W.Check` (`UICheckButtonTemplate` 26 x 26, own `.Text`, ON/OFF sounds via `W.PlayCheckbox`), TOPLEFT (0, -138) in the block, label "Auto-send". Both presets |
| Auto-invite | invite block only. `W.Check`, label "Auto-invite", anchored LEFT = Auto-send's `Text` RIGHT + **16**, same row. Not built for the request block (nothing to invite) |
| Label font | the template's own font object when enabled (not overridden); `GameFontDisableSmall` while disabled |
| Auto-invite enabled | Auto-send checked: normal checkbox, label normal, tooltip as below |
| Auto-invite disabled [D-09] | Auto-send unchecked: `Disable()` (template disabled textures grey the box), unchecked, label `GameFontDisableSmall`, `GetChecked()` false, saved false. It keeps its tooltip (hover still works because the tooltip is on the button frame, which stays mouse-enabled); the tooltip adds a second line "Turn on Auto-send first." in `GRAY_FONT_COLOR`. Fallback when `Text` is a plain FontString: `SetFontObject("GameFontDisableSmall")` on that string, restore the remembered normal object on enable |
| Auto-send turned off while Auto-invite is checked | Auto-invite unchecks, saves false, disables (one handler, order: save, uncheck, disable) |
| Auto-send turned on | Auto-invite enables, stays unchecked |
| Default button | `W.Button`, "Default", **80 x 22**, TOPRIGHT (-6, -140) of the block (right-aligned to the box edge, vertically centred on the 26 px row). Restores the standard message text only (`M.Reset` does not touch Auto-send / Auto-invite); refreshes the box, char count and example. Tooltip "Default" / "Restores the standard message." |
| Example line | `GameFontDisableSmall`, `e.g. ` + `M.Format(kind, sample, boxText)`; sample: the invite block uses the last sample listing (solo), request the first (group); an unknown key renders literally so a leftover `{gs}` is visible. Colour is the font's own grey; no accent |

Vertical fit of the checkbox row: 26 tall at -138 ends -164, example starts -168 (4 px gap). Row of two checkboxes spans x 0 to about 26 + 62 + 16 + 26 + 66 = 196 of 422, clear of the Default button (starts at 336).

## Sending look (contact lock) [D-14 to D-17]

| Aspect | Contract |
|--------|----------|
| Which button | the one clicked: a row Whisper button or the bottom Send Message. The bottom Group Invite is locked by the same lock but is never shown pressed (it only sends a plain invite and starts no lock) |
| Pressed look | `SetButtonState("PUSHED", true)` (locked) from the click until release; release is `SetButtonState("NORMAL")` after exactly 1 s (`GetTime()` deadline + `C_Timer.After(1, ...)`). The whisper is sent before the press |
| Other contact buttons | **unchanged look**: no disabling, no desaturation, no colour change, no tooltip change. Clicks on them return silently (no sound, no prefill, no whisper, no invite) |
| Row recycling | `FillRow` re-applies state on every fill: pressed only when `row.listing.id` equals the locked listing id, otherwise `SetButtonState("NORMAL")`. The bottom Send Message is restored by release / `RefreshButtons` |
| Release | clears pressed on whichever frame holds it, then `T.RefreshAll()` so enabled states recompute (Send Message disabled/enabled follows the selection as in Phase 2) |
| Sent / invited marks | row look from Phase 2 (`messaged` / `invited`) applies after the click as today; the lock look is only the 1 s press |
| Not locked | delist (X), hide/show, selection, sort, search, Messages panel buttons [D-17]; prefill clicks and lockdown clicks start no lock and show no press |
| Preview | same behaviour; `print` line replaces the send; with Auto-invite also the would-invite line |

## Messages side tab (UIP-01) [D-19, D-20, G1-G4]

| State | Look / behaviour |
|-------|------------------|
| Creation | `LargeSideTabButtonTemplate` Frame, TOPLEFT = BOTTOMLEFT of `WhoListingTab`, x 0, y **-2** (stock step, as `Parent.xml:109,119`); `SetChecked(false)` immediately [G1] |
| Icon | `INV_Letter_15`, inset by fill-to-interior: `SetFillToInterior(true)` if the method exists, else set the `fillToInterior` field before the first `SetChecked`; 30 x 30 with texcoord `0.03125-0.96875` retained only as fallback when neither exists [G2] |
| Normal (another tab or Browse showing) | unchecked: stock unselected look, hover highlight from the template |
| Selected (Messages showing) | `SetChecked(true)`; the three stock tabs `SetChecked(false)` |
| Switching away | any stock panel's `OnShow` hides Messages and unchecks ours; `hooksecurefunc(LFGParentFrame, "UpdateTabs", ...)` unchecks the three stock tabs while Messages shows (read-and-set of button state only) [G3] |
| Tooltip | `messagesTab.tooltipText = "Messages"` only; the template shows it (anchored by the template); no `W.Tooltip` hook, no second line [G4] |
| Click | custom mouse-up handler (left, inside) → `ShowMessages`; plays the template's tab sound |
