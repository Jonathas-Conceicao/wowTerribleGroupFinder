## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Saved preset text → outgoing whisper | Player-typed (or SavedVariables-edited) text becomes a chat message to another player |
| Addon → chat / party APIs | Our click handlers call `SendChatMessage` and `InviteUnit` on behalf of the player |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Denial of service (whisper / invite spam to other players) | M.Send / M.StartLock | mitigate | 1 s lock after every real auto-send, `GetTime()` deadline so it holds when the timer is late, generation guard against stale releases; `M.Send` refuses while locked; harness "msg-lock" |
| T-04-02 | Tampering (automated chat in a restricted state) | M.Send | mitigate | Never send during `C_ChatInfo.InChatMessagingLockdown()`: prefill instead, no invite, no lock; harness "msg-lockdown" |
| T-04-03 | Tampering (malformed preset: oversize, pattern injection) | M.Format / M.Normalize | mitigate | Output cut to 255; `[TGF]` escaped as `%[TGF%]`; key values returned from a function (no `%` replacement-string issues); unknown keys stay literal |
| T-04-04 | Elevation of privilege (invite without permission) | M.Send | mitigate | Invite only when `ns.CanInvite()` (Forever's own rule) and only after a real whisper; harness covers the false case |
| T-04-05 | Information disclosure / errors (secret values) | ns.GroupSize | mitigate | `issecretvalue` guard on `GetNumGroupMembers()`; names come from Listings.lua which skips secret listings |
| T-04-06 | Tampering (migration overwrites player text) | M.Init | mitigate | Replace only exact matches of previous defaults, only while `version < 2`, then set version 2; harness "msg-migrate" |
</threat_model>
