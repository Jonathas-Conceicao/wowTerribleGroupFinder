## Phase Details

### Phase 16: Small Improvements

**Goal**: The damage meter prompt can be placed where the player wants and looks like the game's own menus, the Settings page's buttons act at once, whispers to multi-activity listings name the right activity, and new installs aren't asked to reset the meter on every group join
**Depends on**: Nothing (MTR-05, MTR-06, MTR-07, SET-01, MSG-01 and MSG-02 are already prototyped, uncommitted on the milestone branch and harness-tested; MTR-08 is still to be built: the new default off for new installs only, with a schema 3 step in `ns.Migrate` that keeps existing users' value)
**Requirements**: MTR-05, MTR-06, MTR-07, MTR-08, SET-01, MSG-01, MSG-02
**Success Criteria** (what must be TRUE):

  1. Settings > Damage meter > Move closes the options window and shows the prompt to drag; Lock saves the spot and Default returns to the automatic spot (below the zone name and game popups), both reopening the Settings page; the next prompt opens at the saved spot, and a bad saved spot is dropped on load
  2. The prompt shows the addon's purple-eye icon on its left at about its height, with the question and the Yes / No (or Lock / Default) buttons beside it, in the game menu's button style (`SharedButtonTemplate`, the panel button where it's missing)
  3. On a fresh install "Reset when joining a group" is off; a player with saved data from an earlier version still has it on unless they had turned it off
  4. Settings' Move and Edit whisper messages close the options window through its own `Close` (unapplied game settings still ask) and their action follows once it has closed; in combat nothing closes and the action waits as before
  5. Whispering a listing with several activities, where the preset uses `{activity}`, opens a menu at the cursor: picking one whispers with it (as Auto-send says), closing it sends nothing, and Edit only fills the whisper box with every activity (never sends or invites); one activity or no `{activity}` whispers as before

### Phase 999.5: Quest log LFG button for elite quests (BACKLOG)

**Goal**: An LFG button in the quest log for elite (group) quests that opens the group finder for that quest, to search for groups doing it or list yourself / your group for it
**Source**: author request, 2026-11-14 (during v0.2 Phase 8)
**Notes**:

- Open questions: does Forever's finder have activities for quests (a quest / questing category, or only dungeons, raids, zones)? If not, the closest fit (the quest's zone activity, with the quest name in the comment) or a search-box prefill
- Search and create are restricted calls (`C_LFGList.Search` / `CreateListing` need a hardware event and stay Blizzard's): the button can open Browse with the category / activity picked (the game then searches on its own) and open the Listing tab prefilled where that is allowed; the listing description box is secure
- Elite detection: quest log entries flagged elite / group (`C_QuestLog` info: `suggestedGroup`, quest tag / `isElite`), checked against Forever's quest log UI (`wow-ui-source` branch `forever`)
- Placement: a small button on the quest log's quest details (native look), taint-safe (hooks only)
