# Requirements: v0.2.2 Small Improvements

**Defined:** 2026-11-19
**Milestone:** v0.2.2 Small Improvements
**Core Value:** Finding the right players or group fast: the listing must be easy to read and
order (role, level, activity, location) and quick to act on, without leaving or replacing
Forever's own group finder.

## v0.2.2 Requirements

### Damage meter prompt (MTR)

- [x] **MTR-05**: The player can move the damage meter prompt: Settings > Damage meter >
  "Prompt position" > Move shows the prompt to drag; Lock saves the spot, Default goes back to
  the automatic spot (below the zone name and game popups); both open the Settings page again;
  the saved spot is used every time the prompt opens, and a bad saved spot is dropped on load

- [x] **MTR-06**: The prompt's buttons (Yes / No, Lock / Default) use the game menu's button
  style (`SharedButtonTemplate`, the panel button where it's missing)

- [x] **MTR-07**: The prompt shows the addon's purple-eye icon on its left, at about the
  prompt's height, with the question and the buttons beside it

- [x] **MTR-08**: "Reset when joining a group" is off by default for new installs; players who
  already have saved data keep it on unless they turned it off (nothing changes for them)

### Settings page (SET)

- [x] **SET-01**: The Settings page's Move and Edit whisper messages buttons close the options
  window themselves (its own `Close`, so unapplied game settings still ask) and their action
  happens once it has closed; in combat nothing is closed and the action waits as before

### Whispers (MSG)

- [x] **MSG-01**: Where the whisper preset uses `{activity}` and the listing has more than one
  activity, Whisper (row button or Send Message) opens a menu at the cursor with one entry per
  activity; picking one whispers with it, as the preset's Auto-send says; closing the menu sends
  nothing; one activity or no `{activity}` whispers as before

- [x] **MSG-02**: The activity menu has Edit, which only fills the whisper box (never sends or
  invites) with every activity in `{activity}`, for the player to edit

### Release (REL)

- [x] **REL-07**: Release Review for v0.2.2 (code cleanup, changelog draft, the author's review
  of README and changelog), then tag `v0.2.2`
