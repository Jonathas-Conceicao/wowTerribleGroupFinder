<objective>
Build the per-slot gear data for Phase 20: a new module `GearSlots.lua` (`ns.GearSlots`) that reads
one equipped slot's item level, quality, enchant ID, enchant text and whether Forever lets that slot
be enchanted, two read-only exports from `ItemLevel.lua` (the slot names, and whether the latest
inspect answered for a unit), the TOC line, and the `/tgf gear` debug command (a tool shipped
alongside, never a gate, per the kickoff's "implement, don't probe").

Purpose: Plan 02 draws the overlays from `GS.Read`; keeping the data and its states (empty /
pending / known, plus secret) in one place is what keeps "No enchant" from ever showing for data
that hasn't arrived (GEAR-03) and keeps the slot level equal to the figure `ILvl.Read` uses (GEAR-01).
Output: `GearSlots.lua` (data + probe), `ItemLevel.lua` exports, TOC line, `/tgf gear`.
</objective>
