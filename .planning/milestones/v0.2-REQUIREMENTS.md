## v0.2 Requirements

### Gear Score Removal

- [x] **GSR-01**: Gear score is gone from the addon: no GS column, sort, tooltip lines, "Your GS", inspects or saved data; old saved gear score data is cleared on first load (design notes stay in `research/GEARSCORE.md`)

### Item Level

- [x] **ILV-01**: A friendly player's unit tooltip shows "Item Level N" once known (quiet inspect, one at a time; enemies and attackable players never looked up or shown)
- [x] **ILV-02

**: Weapon and armor item tooltips show "Item Level N" in gold right under the item name, exactly once (bags, character sheet, chat links, merchants, loot, comparison tooltips)

- [x] **ILV-03

**: The character sheet's General stats show an Item Level row directly under Movement Speed (equipped item level)

- [x] **ILV-04

**: The Inspect window shows the inspected player's item level as text at its top right

- [x] **ILV-05**: The addon's quiet inspects never disturb the player's own Inspect window and never show another player's value

### Settings

- [x] **SET-01**: The addon has a page in the game's Settings (AddOns), and `/tgf settings` opens it
- [x] **SET-02**: Each item level spot (player tooltip, item tooltip, character sheet, Inspect) can be turned off on its own, taking effect immediately
- [x] **SET-03**: Dynamic refresh can be turned off; the finder then refreshes the stock way (spinner, new list)
- [x] **SET-04**: The swipe animations can be turned off on their own
- [x] **SET-05**: Region flags can be turned off
- [x] **SET-06**: A button in the settings page opens the group finder on the Messages tab
- [x] **SET-07**: Settings are saved across sessions; every option defaults to on

### Dynamic Refresh

- [x] **REF-01**: Refreshing the same category and activities keeps the list and updates it in place: new listings sorted in, delisted ones removed, the selection and whispered / invited marks kept; a failed refresh keeps the list
- [x] **REF-02**: Rows that leave swipe out and new rows swipe in, at a calmer speed than the prototype
- [x] **REF-03**: Rows below a removed row slide up into place instead of jumping
- [x] **REF-04**: In preview mode, the refresh button simulates listings leaving and arriving with the same animations

### Region Flags

- [x] **REG-01**: Each listing shows a flag after the name: one US flag for US East and US West, an Oceania flag; listings on unknown servers show none
- [x] **REG-02**: The row tooltip names the region (US East, US West or Oceania). *Adjusted 2026-11-15: the tooltip names the game's shard group ("US1", "US2", "AU1"), with no West / East assumed; generic for other regions*
- [x] **REG-03**: Your own listing shows the flag of its group leader's region
- [x] **REG-04**: The servers known to the addon grow as you play (your own, Battle.net friends') and are saved

### Row Icons

- [x] **ICO-01**: Every icon on a finder row shows a tooltip on hover saying what it is (region flag, role icons, new player friendly, Discord, leader, friend / Battle.net friend / recent ally marks, friends in group)
- [x] **ICO-02**: Hover, click and right-click on a row keep working over its icons

### Release

- [x] **REL-05**: Release Review: code cleanup, CLAUDE.md and README updated, version v0.2.0, changelog draft, author review

## Out of Scope

| Feature | Reason |
|---------|--------|
| Per-slot item levels on the character sheet / Inspect slots | Not asked for; clutters the stock look |
| Colour-coded or score-like item level | Item level stays the game's own number; gear score is dropped for being ours |
| Sorting or filtering the finder by item level | Listings carry no item level; only known players have one |
| Saving inspected players' item levels between sessions | Values change; session-only keeps them honest |
| Refresh on a timer | `C_LFGList.Search` from a timer is blocked by the game (`ADDON_ACTION_BLOCKED`) |
| Turning off the finder changes themselves | The table in the finder is the addon; disable the addon instead |
| A custom-skinned settings window | Native look: the game's Settings panel |
