# Flag sources

Flags from flagpedia.net (flagcdn.com), w40 PNGs, public domain; supplied by the author 2026-11-16.

`Media/Source/png2tga.js` converts each `flag_<cc>.png` here to `Media/Textures/flag_<cc>.tga` (pixels copied 1:1 onto a transparent 64x32 canvas; nothing drawn). Run it with `node Media/Source/png2tga.js` from the repo root. This folder does not ship.
